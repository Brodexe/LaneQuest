# Game slop: progression and economy

Applies to: score, rewards, costumes, unlocks, loot, crafting, upgrades, skill trees, monetization, base-building, meta-progression.

- **G2** Crafting systems with dozens of interchangeable junk items.
- **G3** Skill trees padded with incremental stat boosts.
- **G4** Loot rarity tiers that inflate numbers rather than change gameplay.
- **G7** Daily login rewards.
- **G8** Battle passes with artificial progression grinds.
- **G9** Randomized loot boxes.
- **G37** Weapon attachments that only improve statistics.
- **G44** Base-building systems where structures provide passive numerical bonuses.
- **G45** Automated resource generators that eliminate resource decisions.
- **G48** Roguelike runs built around stacking random numerical upgrades.
- **G50** Meta-progression that makes repeated runs easier without teaching new skills.
