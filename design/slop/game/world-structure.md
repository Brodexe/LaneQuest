# Game slop: world structure

Applies to: procedural generation, level variety, open areas, level structure, run structure, crafting stations, extraction.

- **G1** Procedurally generated worlds with little meaningful variation.
- **G6** Generic crafting benches scattered across the map.
- **G27** Open worlds filled with copy-pasted landmarks.
- **G49** Extraction mechanics added without meaningful risk-reward decisions.
