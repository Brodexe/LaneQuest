# Map slop: scale

Applies to: sizing any prop, building, door, furniture, plant, or platform relative to the player character.

- **M12** Oversized props that make the world feel like a toy set unintentionally.
- **M13** Inconsistent scale between the player, furniture, doors, and buildings.
- **M38** Scale-model vegetation: Grass blades, flowers, bushes, and trees have wildly inconsistent scales relative to the player.
